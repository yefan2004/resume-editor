# 简历编辑器

一个使用原生 HTML、CSS 和 JavaScript 开发的双栏 A4 简历编辑器。

无需安装、无需注册、无需服务器，打开网页即可编辑。简历内容和照片均在用户本机浏览器中处理，不会主动上传到服务器。

![界面预览](assets/preview.png)

## 在线使用

访问：

[https://github.com/yefan2004/resume-editor](https://你的GitHub用户名.github.io/robot-resume-editor/)

推荐使用最新版 Microsoft Edge 或 Google Chrome。

## 离线使用

1. 在项目页面点击 `Code → Download ZIP`；
2. 解压下载的 ZIP 文件；
3. 使用 Edge 或 Chrome 打开 `index.html`；
4. 点击简历中的文字直接修改；
5. 点击照片框上传并裁剪照片；
6. 点击“打印 / 导出 PDF”生成简历。

## 导出 PDF

1. 点击页面顶部的“打印 / 导出 PDF”；
2. 打印目标选择“另存为 PDF”；
3. 展开“更多设置”；
4. 纸张选择 A4；
5. 勾选“背景图形”；
6. 保存 PDF。

如果没有勾选“背景图形”，蓝色侧栏可能无法正常显示。

## 主要功能

- 双栏 A4 简历排版
- 点击文字直接编辑
- 浏览器本地自动暂存
- 上传、拖入或粘贴证件照
- 照片拖动、缩放和旋转裁剪
- 新增和删除工作经历
- 纯文本粘贴，避免带入网页或 Word 样式
- 打印和导出 PDF
- 导出可继续编辑的独立 HTML
- 纯前端运行
- 支持离线使用
- 不包含第三方 JavaScript 依赖

## 数据与隐私

本项目为纯前端应用，不包含后端服务器接口，也不会主动上传简历内容或照片。

用户填写的数据默认保存在浏览器的 `localStorage` 中。不同浏览器、不同设备和不同网站地址之间的数据通常不会互通。

请注意：

- 清除浏览器网站数据后，本地暂存可能丢失；
- 无痕模式关闭后，暂存数据通常会被清除；
- 请及时导出 HTML 或 PDF 进行备份；
- 请勿在公共电脑上长期保存包含个人信息的简历；
- 使用公共电脑后，建议点击“恢复模板原文”清除暂存。

## 使用说明

### 编辑文字

点击简历中的可编辑文字即可直接修改。

页面会在输入停止约 300 毫秒后自动暂存。

### 添加照片

支持以下方式：

- 点击照片框选择图片；
- 将图片文件拖入照片框；
- 从剪贴板粘贴图片。

选择图片后可以：

- 拖动调整位置；
- 使用鼠标滚轮缩放；
- 使用滑杆调整缩放、横移、纵移和旋转；
- 点击“应用到简历”完成裁剪。

### 清除照片

点击照片框使其获得焦点，然后按 `Delete` 或 `Backspace`。

### 新增工作经历

点击顶部工具栏中的“新增工作经历”。

新增的经历可以通过该段上方的“删除这段经历”按钮删除。

### 隐藏提示行

点击顶部工具栏中的“清除提示行”。

提示行默认不会进入打印结果。

### 恢复空白模板

点击“恢复模板原文”。

该操作会清除当前页面对应的文字和照片暂存，且无法撤销。

### 导出可编辑 HTML

点击“另存为文件”。

导出的 HTML 包含当前简历内容和裁剪后的照片，可以离线打开并继续编辑。

## 常见问题

### 打开页面后仍然显示以前填写的内容

这是浏览器自动恢复了本地暂存。

如果不再需要原内容，请点击“恢复模板原文”。

### PDF 没有蓝色背景

在打印窗口的“更多设置”中勾选“背景图形”。

### 刷新后内容没有恢复

可能原因：

- 浏览器禁止本地存储；
- 当前处于无痕模式；
- 浏览器存储空间不足；
- 使用了不同网址或不同浏览器；
- 手动清除了网站数据。

建议使用“另存为文件”定期备份。

### 上传照片后提示存储空间不足

请尝试：

- 使用尺寸较小的照片；
- 清除该页面的旧数据；
- 导出 HTML 后继续编辑；
- 使用最新版 Edge 或 Chrome。

### 从 Word 粘贴后格式没有保留

这是预期行为。

编辑器会尽量只粘贴纯文本，避免 Word 或网页样式破坏简历排版。
